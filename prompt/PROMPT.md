这是一场公开的 AI 编程对抗赛「AI 像素擂台」第 1 集：贪吃蛇大乱斗。10 个 AI 模型拿到一字不差的同一份提示词，各自写一个贪吃蛇程序，然后这些程序在同一个赛场里打几千局，按真实成绩公开排名。你的对手是其他顶尖 AI 写的程序，它们会抢食物、截你的路、和你撞头。请写出你能写的最强程序。

## 比赛方式

- 你只有这一次写程序的机会。你看不到裁判代码，也不能先试打，请在这次回复里交出最终版本。
- 交卷后，裁判先跑一轮自检：12 局，对手全是陪练基准。只有自检出错（代码报错、超时、返回值不对、进程卡死）时，你会收到一份错误报告，最多有 2 次修复机会。自检通过就直接进入正式赛，不会再联系你。
- 陪练基准是一个中等强度、思路常规的程序（避开马上会死的方向，看空间，追最近的食物）。它在正式排名里是 0 分线。赢过基准不代表够强，正式对手远强于它。
- 正式赛有两种赛制，各占一半权重：
  - 单挑：2 条蛇，15×15，最多 500 回合。
  - 大乱斗：11 条蛇（10 个 AI 加陪练基准），31×31，最多 800 回合。
- 座位和种子轮换。每局按名次拆成两两比较，用 Bradley–Terry 模型拟合实力值。

## 规则

**棋盘**：正方形网格，四周是墙，场内没有障碍。坐标 (x, y)，x 从左到右是 0 到 宽-1，y 从上到下是 0 到 高-1。"up" 是 y 减 1，"down" 是 y 加 1，"left" 是 x 减 1，"right" 是 x 加 1。

**开局**：每条蛇长 3 节，3 节叠在出生点同一格，走几步才会展开。单挑的两条蛇分别在 (3, 3) 和 (11, 11)；大乱斗的 11 条蛇沿一圈均匀排开。场上始终保持"蛇的条数 + 1"颗食物（单挑 3 颗，大乱斗 12 颗），位置随机。

**每回合**，所有活着的蛇同时给出一个方向，然后按这个顺序结算：

1. 移动：每条蛇的头朝选定方向走一格，尾巴同时缩回一格。掉头（走回自己脖子那一格）无效，按原方向继续走。
2. 饥饿：每条蛇的生命值减 1。生命值上限 100，开局是 100。
3. 吃食物：蛇头所在格有食物就吃掉，生命值回满 100，身体长 1 节（新的一节加在尾巴上，所以吃到后的下一回合尾巴不动）。两条蛇的头同时到达一颗食物时，两条都算吃到。
4. 淘汰（同时判定）：
   - 头走出棋盘：死。
   - 生命值降到 0：饿死。
   - 头撞到任何一条蛇的身体（除蛇头以外的任意一节，包括自己的）：死。尾巴在第 1 步已经缩回，所以可以跟着别人的尾巴走；但刚吃过食物的蛇尾巴不动。
   - 两个或更多蛇头进了同一格：最长的那条活下来，其余的死；一样长就都死。
   - 死掉的蛇立刻从棋盘上消失。
5. 补食物：被吃掉的食物在随机空格重新出现。

**结束**：只剩 1 条或 0 条蛇，或者到了回合上限。

**名次**：死得越晚名次越靠前。同一回合死的，长的在前；活到最后的排在所有死蛇前面，活着的之间也比长度。长度也一样就并列。也就是说，**先活下来，再比长**。

## 程序接口

- 语言：Python 3.13，只能用标准库。交一个文件 `bot.py`。
- `bot.py` 里要有函数 `decide(state)`，返回 `"up"`、`"down"`、`"left"`、`"right"` 之一。每回合调用一次。
- 每局开始时，裁判在一个新的独立进程里重新加载 `bot.py`，所以模块级的全局变量可以用来在同一局的回合之间保存信息，下一局会清零。
- `random` 模块已经由裁判按每局的种子初始化，可以直接用。
- 时限按 CPU 时间算：加载代码 1 秒，第 1 回合 1 秒，之后每回合 50 毫秒。超时、抛出异常、返回值不对，这一回合都按原方向直行；连续 3 次，或者一次超过 3 秒没回应（进程会被结束），本局剩下的回合都直行。
- 不能读写文件、联网、启动子进程。程序运行在沙箱里，这些操作会直接失败。`print` 的内容会被丢掉，不影响比赛。

`state` 是一个 dict，例子（单挑第 37 回合，你是 1 号）：

```python
{
    "turn": 37,            # 即将进行的回合，从 1 开始
    "max_turns": 500,
    "width": 15,
    "height": 15,
    "num_snakes": 2,       # 这一局开局时的蛇数
    "you": 1,              # 你的蛇的 id
    "snakes": [            # 所有还活着的蛇，包括你自己；死了的不在里面
        {"id": 0, "body": [[5, 7], [5, 8], [6, 8], [7, 8]], "health": 81, "length": 4},
        {"id": 1, "body": [[9, 3], [9, 4], [9, 5], [9, 5]], "health": 100, "length": 4},
    ],
    "food": [[2, 2], [12, 9], [7, 7]],
}
```

`body[0]` 是蛇头，最后一个是蛇尾。像上面 1 号蛇那样最后两节重叠，说明它刚吃到食物，下一回合尾巴不动。
